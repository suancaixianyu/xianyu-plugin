# xianyu-plugin 说明

`xianyu-plugin`是一个`Yunzai-Bot`的小游戏插件，目前提供一些棋类游戏，例如`象棋` `国际象棋` 以及 `扫雷`

具体功能可在安装插件后 ~~**自行摸索**~~

---

## 安装与更新

### 使用 Git 安装（推荐）

请使用 git 进行安装，以方便后续升级。在 Yunzai-Bot 根目录夹打开终端，运行下述指令

```
git clone --depth=1 https://gitee.com/suancaixianyu/xianyu-plugin.git ./plugins/xianyu-plugin/
```

进行安装。安装完毕后，管理员只需发送 `#咸鱼更新` 即可自动更新 xianyu-plugin。

## 设置

`#咸鱼设置按钮 开启/关闭`控制按钮是否显示，默认关闭按钮

详情请发送 `#咸鱼帮助` 查看

## Yunzai 版本与支持

`xianyu-plugin` 仅支持 V3 版本的 Yunzai-Bot，v4 正在适配中

其他版本自行测试，如有报错可以提交一个`lssues`反馈

也可以关注一下`xianyu-plugin`官网 [☛ 咸鱼插件](https://suancaixianyu.cn/)

## 说明

基于alemonjs开发的游戏插件

## 使用

| 指令                       | 作用                                         |
| -------------------------- | -------------------------------------------- |
| /扫雷帮助                  |                                              |
| /扫雷                      | 开始游戏，如果游戏正在进行会直接显示当前进度 |
| /结束扫雷                  |                                              |
| /扫雷难度 <简单/中等/困难> | 使用不同难度进行游戏                         |
| /翻开 <坐标>               | 坐标不区分大小写，不数量                     |
| /标记 <坐标>               | 坐标不区分大小写，不数量                     |
| /取消标记 <坐标>           | 坐标不区分大小写，不数量                     |
